# Markus Co

Sajt porodične firme Markus Co iz Valjeva, proizvođača vlažnih maramica. Next.js aplikacija sa srpskim i engleskim jezikom.

Potreban je Node.js 20.9 ili noviji.

```bash
npm run dev
npm run build
npm run lint
```

`dev` pokreće lokalni server, `build` pravi produkcijsku verziju, `lint` proverava kod.
